謝爾賓斯基三角形

一個挖不完洞的三角形：越放大，看到的越多，而且永遠長得一樣。

做法：一直挖洞

1. 畫一個實心的正三角形。

2. 連接三邊的中點，把中間那個倒三角形挖掉，剩下 3 個小三角形。

3. 對每個小三角形重複第 2 步……永遠做下去。

最後留下來的，就是謝爾賓斯基三角形。波蘭數學家謝爾賓斯基在 1915 年研究了它。

奇怪的數字

每挖一層：三角形變 3 倍多，面積只剩 3/4，周長卻變 3/2 倍。

面積 = (3/4)ⁿ → 0　　周長 = (3/2)ⁿ → ∞

挖到無限多層時：面積是 0，周長卻無限長！它比一條線「大」，又比一塊面「小」。

它是幾維的？

把圖形邊長放大 2 倍，看看會變成幾個原本的自己：

線段：2 個
2¹ = 2 → 1 維
正方形：4 個
2² = 4 → 2 維
謝爾賓斯基：3 個
2d = 3 → d ≈ 1.585 維

維度不是整數的圖形，叫做碎形（fractal）。

混沌遊戲為什麼會成功？

每次「往頂點走一半」，就等於把整張圖縮小一半，貼到那個頂點的角落。謝爾賓斯基三角形剛好由 3 個「縮小一半的自己」組成，所以亂跳的點會越來越靠近它，而且一旦落進圖形附近，就再也跳不進洞裡。

改成正方形時，4 個縮小一半的正方形剛好把原本的正方形填滿，所以畫不出任何圖案。

巴斯卡三角形的祕密

巴斯卡三角形每個數字等於上面兩個數字的和。只看奇偶：奇+奇=偶、奇+偶=奇，這個規則和挖洞的規則一模一樣，所以奇數的位置會排出謝爾賓斯基三角形。

（上左 + 上右）÷ 2 的餘數

生活中的謝爾賓斯基

• 義大利中世紀教堂的科斯馬蒂鑲嵌地板（13 世紀），工匠早就鋪出好幾層的三角形挖洞圖案。

• 有些芋螺的貝殼花紋，看起來很像一層層的三角形，可以用簡單的規則（細胞自動機）模擬出來。

• 工程師做過碎形天線：形狀像謝爾賓斯基三角形，可以在小小的空間裡接收好幾種頻率。

時間軸

  • 1653巴斯卡寫下關於「算術三角形」的論文
  • 1915謝爾賓斯基發表這個三角形
  • 1975曼德博創造「碎形」（fractal）這個詞
  • 1988巴恩斯利在《處處都是碎形》書中推廣「混沌遊戲」
