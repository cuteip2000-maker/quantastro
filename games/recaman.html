輸入一個數，看看它在第幾步第一次出現。

Recamán 跳跳數列

從 0 出發，第 n 步跳 n 格。規則只有一行，卻畫出漂亮的拱橋，還藏著一個到今天沒人能回答的問題。

完整的規則

第 n 步（n ＝ 1, 2, 3, …）：

先試著往左跳 n 格。
如果落點 ＞ 0，而且這個數還沒出現過 → 往左。
否則 → 往右跳 n 格。

網路上常只寫「是正的就往左」，漏了「還沒出現過」這個條件。少了它，數列就不一樣了。

誰想出來的？

哥倫比亞數學家伯納多・雷卡曼（Bernardo Recamán）在 1991 年把它寄給整數數列大全（OEIS）的創辦人斯隆，編號 A005132。

畫成半圓拱橋、再把每個數換成音高，它就成了一段奇特的音樂，所以在網路上很有名。

還沒解開的謎

同一個數有時會出現兩次（第一個是 42）。但是：每一個正整數，最後都會出現嗎？

斯隆猜答案是「會」，但沒有人能證明。有些很小的數要等很久：19 要到第 99734 步才出現。我們用電腦算到第 300 萬步，1355 還沒有出現。
